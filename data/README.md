# Life in the UK question data

The files in this directory are generated by
`scripts/scrape_lifeintheuktestweb_exams.py` after the user confirmed that
they have permission to extract and use the 17 exam sets.

- `lifeintheuktestweb_exams_1_17.json`: questions grouped into the original 17 exams.
- `lifeintheuktestweb_questions.json`: flat, read-only source used by the enrichment generator.
- `lifeintheuktestweb_duplicate_report.json`: exact-question duplicate audit.
- `enriched_exams/exam-XX.json`: application-ready data split into 17 Exam files, each containing 24 questions, explanations, the sources used by that Exam, and visual metadata.
- `explanations_zh/exam-XX.json`: Chinese explanation source text split into 17 Exam files.
- `authority_sources.json`: reusable authoritative-source registry and handbook chapter mapping.

Each record retains its source page URL. The importer preserves visible question
and option wording, while normalising HTML layout whitespace.

Run `scripts/prepare_ai_visual_manifest.py` to audit question-and-answer-specific
AI learning illustrations under `public/images/ai/`. Exact duplicate questions
reuse the first stable question ID, so 397 compressed WebP files cover 401
question records. Five film questions keep their attributed real posters and two
questions keep selected real artwork or photography.

Run `scripts/enrich_question_content.py --exam N` to regenerate only one Exam's
runtime data and 24 original answer-memory SVG fallbacks. Omit `--exam` to rebuild
all 17 Exam files. The generator prefers an AI WebP only when the corresponding
file exists. All answer visuals appear after the learner answers. Run
`scripts/validate_enriched_content.py` to audit all 17 files together.
